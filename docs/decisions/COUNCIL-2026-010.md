# COUNCIL-2026-010: Zero-Knowledge Ad-Free 'Focus Pass' Attention Windows and Editorial Zen Stream Mode

**Status:** RATIFIED — Completed
**Date:** 2026-09-20
**Council:** Architecture Council, AdMe (6/6 ratified)
**Related:** COUNCIL-2026-001
**Tags:** council, automatic, live-governance, privacy, location

## Context
Digital advertising fatigue occurs when users feel captive to an unending stream of promotional interruptions. In conventional ad networks, ad blockers and user churn are the only escape, starving ethical publishers and merchants. In AdMe's value-exchange economy, consumers earn reward points through intentional dwell time, brand trivia quizzes, and authentic feedback. Users need a direct mechanism to 'buy back their peace of mind' by redeeming accumulated points for time-bounded, ad-free 'Focus Passes' (e.g. 15-minute quick sprint, 1-hour deep work, 24-hour day of calm) where commercial ads are completely silenced and replaced with an inspiring, aesthetic Editorial Zen Stream without requiring paid credit cards or server-side telemetry.

## Decision
Implement an end-to-end Zero-Knowledge Ad-Free 'Focus Pass' & Editorial Zen Stream Mode: 1. Focus Pass Redemption & Vault Engine: Add dedicated 'Ad-Free Focus Pass' tiers (15m Sprint / 100 pts, 1h Deep Work / 250 pts, 24h Day of Calm / 500 pts) to the Rewards Store (/rewards) that deduct points via the secure ledger and activate an encrypted, local time-stamped Focus Pass. 2. Complete Ad Suppression in Feed & Radar: While Focus Pass is active, suppress all commercial sponsored cards, carousel promotions, and geofence deal push banners across Feed.tsx and GeofenceAlert.tsx. 3. Aesthetic Editorial Zen Stream: Transform the feed during Focus Mode to display tranquil curated photography, thoughtful quotes, and mindfulness micro-articles with zero commercial clutter. 4. Floating Focus HUD & Zen Countdown: A minimalist, collapsible floating Zen timer widget displays remaining ad-free duration, zen mode toggles, and instant extension options. 5. Zero-Knowledge Privacy Preservation: Focus state, remaining minutes, and focus sessions are managed client-side with tamper-evident expiry verification, preventing central logging of user focus habits.

## Amendments Adopted
1. Focus Pass expiration tokens must be cryptographically signed using a locally derived client-side keypair to prevent manual LocalStorage clock tampering.
2. Editorial Zen Stream assets must be loaded via static bundles or cached IPFS/CDN nodes to prevent any telemetry leakage during zen mode activation.

## Implementation Mandate
Implement point deduction RPC endpoints in `/rewards`, create client-side HMAC token validation for local focus state in `hooks/useFocusPass.ts`, update `Feed.tsx` and `GeofenceAlert.tsx` to respect suppression flags, and build the floating Zen HUD widget.

## Council Deliberations
### 🏛️ The Architect (YES)
The client-side token architecture for the Focus Pass prevents central correlation of focus habits while utilizing React Context and LocalStorage with tamper-evident HMAC signing. Feed.tsx and GeofenceAlert.tsx will conditionally render Zen content without breaking existing virtualized lists.

### ⚙️ The Engineer (YES)
TypeScript types for FocusPassTier and encrypted local state are robust. Using requestAnimationFrame for the floating Zen HUD ensures smooth 60fps countdowns without unnecessary React re-renders.

### 🛡️ The Security Lead (YES)
Achieves absolute zero-knowledge compliance: servers only process the ledger point deduction transaction. The active focus window, expiration timestamp, and content preferences remain strictly client-side.

### 🎯 The Product Owner (YES)
This solves ad fatigue elegantly. Users trade hard-earned attention points for autonomy and peace of mind, reinforcing AdMe's ethical value-exchange without relying on subscriptions or tracking.

### 🧪 The QA Lead (YES)
Test coverage will include mock clock manipulations for expiration verification, ledger sync failure rollbacks, and offline local-storage tampering edge cases across Feed and Geofence alerts.

### 💾 The Data Engineer (YES)
Zero schema modifications required on the backend for focus states. Point redemptions map cleanly to existing ledger debit transactions with zero persistent tracking of dwell times or session lengths.
