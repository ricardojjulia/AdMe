# Council Reviews & Audit Reports

This directory stores outputs generated by the 5-Agent Council Review & Software Factory Protocol defined in [`improve-software.md`](../../improve-software.md).

## Stored Artifacts per Council Round

For every non-trivial merge cycle or periodic governance review, commit the following files:
- `YYYY-MM-DD-council-review-[N]-synthesis.md`: Cross-agent consensus, prioritized actions, and software factory implementation prompts.
- `YYYY-MM-DD-council-review-[N]-agent-1-data-api.md`: Data layer, RLS, and API route audit report.
- `YYYY-MM-DD-council-review-[N]-agent-2-routes-pages.md`: Shell, route existence, and handler completeness report.
- `YYYY-MM-DD-council-review-[N]-agent-3-ux-shell.md`: ARIA accessibility, responsive styling, loading/error states report.
- `YYYY-MM-DD-council-review-[N]-agent-4-feature-competitive.md`: Core workflow completion and readiness score report.

A Council round is officially complete when these reports and the Documenter's plan/changelog updates are committed to the repository.
