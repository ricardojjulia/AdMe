# COUNCIL-2026-014: Mindful Attention Budget & Digital Wellness Dividend: Voluntary Daily Exposure Caps, Anti-Doomscrolling Soft Ceilings, and Mindful Streak Rewards

**Status:** RATIFIED — Implemented & Verified
**Date:** 2026-09-30
**Council:** Architecture Council, AdMe (6/6 ratified)
**Related:** COUNCIL-2026-001
**Tags:** council, automatic, live-governance, privacy, location

## Context
Traditional digital ad platforms deploy predatory algorithmic feedback loops designed to trap users in indefinite doomscrolling, generating cognitive exhaustion, resentment, and acute ad blindness. Consumer psychology research proves that respect for user time is the single greatest driver of brand goodwill and ad recall. Consumers strongly prefer platforms where commercial exposure is finite, intentional, and self-regulated. Users want the agency to set a voluntary daily ad consumption budget (e.g., 3, 5, or 10 ads per day), visualize their attention-to-reward ratio in real-time, and experience a celebratory 'All Caught Up' soft ceiling that suppresses commercial clutter once their mindful budget is achieved while awarding a Daily Mindful Completion Dividend bonus.

## Decision
Implement an end-to-end Mindful Attention Budget & Digital Wellness Dividend Engine across AdMe: 1. Client-Side Mindful Attention Engine (src/lib/services/attention-budget.ts & useAttentionBudget.ts): Pure TypeScript state and calculation engine tracking daily ad exposures, user-configured budget caps (3, 5, 10, or unlimited ads/day), mindful daily completion streaks, and bonus dividend claims. 2. Feed Header Mindful Attention Ring & Budget Pill (AttentionBudgetHUD.tsx): An elegant, non-intrusive floating progress pill atop the consumer feed showing remaining ad quota, total points earned in current session, and 1-click budget customization modal. 3. Celebratory 'Mindful Goal Reached' Feed Milestone Card (MindfulCeilingCard.tsx): When the daily budget is met, commercial ads are gracefully suppressed, presenting an empowering milestone card offering a +25 pt Daily Mindful Completion Dividend, streak tally, and automatic switch to pure community/zen stream. 4. Interactive Budget Controls in Ad Controls / Profile (/profile): Slider and quick-preset controls allowing users to adjust their target daily ad threshold, view their 7-day attention discipline history, and reset or extend their session voluntarily. 5. Strict Zero-Knowledge Ephemerality: All budget counters, timestamps, and streak tallies persist strictly in client-side localStorage ('adme_attention_budget_v1') without server-side tracking, cookies, or profiling, with 100% bilingual localization (en-US, es-PR). 6. Comprehensive Verification: Complete unit test coverage in Vitest, end-to-end user journey validation in Playwright, and verification through the 6-tier software release pipeline.

## Amendments Adopted
1. Ensure streak calculation uses UTC calendar days to avoid timezone manipulation exploits or unexpected resets.
2. Mandate 100% bilingual localization coverage (en-US, es-PR) for all strings in AttentionBudgetHUD, MindfulCeilingCard, and profile sliders.
3. Implement safe JSON parsing with fallback defaults for localStorage access to protect against corrupted state or private browsing mode storage blocks.

## Implementation Mandate
Proceed with development across src/lib/services/attention-budget.ts, useAttentionBudget.ts, AttentionBudgetHUD.tsx, MindfulCeilingCard.tsx, and /profile integration. Enforce strict localStorage use ('adme_attention_budget_v1'), zero server-side tracking, bilingual en-US/es-PR localization, Vitest unit testing, and Playwright end-to-end verification.

## Council Deliberations
### 🏛️ The Architect (YES)
The proposed client-side service architecture in `src/lib/services/attention-budget.ts` combined with `useAttentionBudget.ts` cleanly isolates state management away from server side components. Using React hooks to manage local storage sync prevents hydration mismatches in Next.js by deferring local storage reads to `useEffect` or utilizing safe initializers.

### ⚙️ The Engineer (YES)
Implementation details are tight. Pure TypeScript state computation ensures zero unnecessary re-renders. We should ensure the localStorage schema has a robust migration path (`adme_attention_budget_v1`) to handle future property additions gracefully without throwing parsing exceptions.

### 🛡️ The Security Lead (YES)
Strict adherence to zero-knowledge ephemerality by completely bypassing server-side tracking, cookies, and fingerprinting for ad consumption budgets sets a gold standard for privacy. Storing data exclusively in `localStorage` guarantees user ownership and transparency.

### 🎯 The Product Owner (YES)
This directly aligns with AdMe's value proposition of respecting user time and reversing toxic algorithmic loops. Empowering users with configurable caps (3, 5, 10 ads/day) and rewarding them with a +25 pt Daily Mindful Completion Dividend creates undeniable brand goodwill and high-intent ad recall.

### 🧪 The QA Lead (YES)
Comprehensive verification with Vitest for state services and Playwright for end-to-end user journeys guarantees robust delivery. Edge cases like date roll-over (UTC vs local time) for streaks must be carefully mocked in unit tests.

### 💾 The Data Engineer (YES)
Zero database schema modifications required! By maintaining absolute zero-retention on the server side for attention budgets and streak metrics, we eliminate compliance overhead while preserving complete client autonomy.
